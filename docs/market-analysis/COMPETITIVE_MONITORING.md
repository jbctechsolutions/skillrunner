# SkillRunner Competitive Monitoring System

**Created:** December 4, 2025
**Review Cadence:** Weekly (30 min) + Monthly (2 hrs)

---

## Purpose

Track competitor movements to know when to:
1. **Pivot** - Competitor copies your differentiator
2. **Accelerate** - Opportunity window closing
3. **Reposition** - Market shifting
4. **Stop** - Market conditions make success unlikely

## Kill Signals (Stop Immediately If...)

### RED ALERTS - Reconsider Continuing

| Signal | What It Means | Response |
|--------|---------------|----------|
| Factory adds per-request cost tracking | Core differentiator gone | Evaluate within 1 week |
| Ollama announces workflow layer | Distribution channel closed | Pivot or partner immediately |
| 3+ major tools add cost tracking | No longer unique | Pivot to different positioning |
| Your GitHub stars plateau at <500 for 3 months | No market interest | Consider stopping |

### YELLOW ALERTS - Accelerate or Pivot

| Signal | What It Means | Response |
|--------|---------------|----------|
| Factory adds "cost mode" or similar | They're noticing the gap | Accelerate skill decomposition |
| Cline launches CLI version | Competition in your space | Differentiate harder on optimization |
| Aider adds workflow features | Market validating workflows | Good - means demand exists |
| New well-funded entrant with cost focus | Direct competition | Evaluate their positioning |

### GREEN SIGNALS - Keep Going

| Signal | What It Means | Response |
|--------|---------------|----------|
| Users mention cost savings unprompted | Positioning resonates | Double down |
| Competitors raise prices | Cost sensitivity growing | Emphasize savings |
| "AI costs" trending on HN/Reddit | Problem awareness growing | Content marketing opportunity |
| Enterprise inquiries (any) | Market expanding | Consider enterprise pivot |

## Decision Framework

### Monthly Health Check

Score each factor 1-5:

| Factor | Score | Notes |
|--------|-------|-------|
| Competitor distance (are they catching up?) | /5 | |
| User growth (GitHub stars, WAU) | /5 | |
| Feedback quality (cost mentions) | /5 | |
| Feature progress (on roadmap?) | /5 | |
| Personal motivation | /5 | |
| **TOTAL** | /25 | |

**Interpretation:**
- 20-25: Strong position, keep building
- 15-19: Solid, address weak areas
- 10-14: Concerning, consider pivot
- <10: Stop and reassess

---

## Quarterly Strategy Review

### Every 3 Months: Big Picture

1. **Market Position**
   - Are we still differentiated?
   - Has the competitive landscape shifted?
   - Are there new entrants?

2. **Traction Assessment**
   - GitHub stars trend
   - User growth trend
   - Conversion to paid (if applicable)
   - Community engagement

3. **Roadmap Relevance**
   - Are planned features still differentiating?
   - Should priorities shift?
   - Are there new opportunities?

4. **Go/No-Go Decision**
   - Continue as planned?
   - Pivot positioning?
   - Pivot product?
   - Stop?
