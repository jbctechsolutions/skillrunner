## With Traction Options ($305K-1.3M+)

### NSF SBIR Phase I (Non-Dilutive)

| Detail | Value |
|--------|-------|
| Amount | Up to $305,000 |
| Equity | None - retain full ownership + IP |
| Timeline | Project Pitch anytime, then invitation |
| Phase II | Up to $1.25M over 24 months |

**WARNING:** Congressional authority expired Sept 30, 2025. Verify program status before applying.

**Application:** [seedfund.nsf.gov](https://seedfund.nsf.gov/)

### Earnest Capital / Calm Company Fund

| Detail | Value |
|--------|-------|
| Amount | $75,000 - $250,000 (avg ~$100K) |
| Requirements | Paying customers, recurring revenue |
| Structure | SEAL (Shared Earnings Agreement) |
| Repayment | 2x-5x cap, from founder earnings |

**Best for bootstrappers.** Limited dilution, can buy back equity.

**Application:** [calmfund.com](https://calmfund.com/for-founders)

### Horizon Europe NGI (EU Grants)

| Detail | Value |
|--------|-------|
| Amount | 5,000 - 120,000 |
| Focus | Open source, digital infrastructure |
| Participants | EU and international welcome |

1,200+ projects funded (~140M distributed).

**Application:** [Monitor NGI open calls](https://interoperable-europe.ec.europa.eu/collection/open-source-observatory-osor/funding-opportunities-open-source-software-projects-public-sector)

## Key Success Factors

### What Makes Applications Strong

1. **Clear open source commitment** - OSI-approved license, public repo
2. **Documentation** - README, Code of Conduct, contribution guidelines
3. **Community engagement** - Discord, GitHub discussions, social presence
4. **Unique value proposition** - Cost tracking differentiator is compelling
5. **Local-first privacy angle** - Appeals to EU grants (NGI, NLnet)

### Application Tips

| Grant | Emphasize |
|-------|-----------|
| NLnet | "Next Generation Internet" angle - privacy, decentralization |
| GitHub OSS | Security practices, dependency management |
| NSF SBIR | Innovation, R&D, societal benefit |
| YC Build Sprint | Execution speed, clear milestones |
| Earnest Capital | Revenue model, sustainability, founder-market fit |

## Risk Mitigation

### Diversification Strategy

Don't rely on single funding source:

1. **Cloud credits** - Low risk, high approval rate
2. **Foundation grants** (NLnet, GitHub OSS) - Medium competition
3. **Community funding** (Open Collective, Sponsors) - Build over time
4. **Government grants** (SBIR) - High value, high competition

### Backup Plans

| If This Fails | Do This Instead |
|---------------|-----------------|
| NLnet rejection | Horizon Europe NGI calls |
| GitHub OSS rejection | Vercel + NumFOCUS combination |
| NSF SBIR unavailable | Focus on Earnest Capital |
| Cloud credits expire | Hetzner (very affordable alternative) |

## Important Warnings

1. **NSF SBIR/STTR** - Congressional authority expired Sept 30, 2025. Verify status before investing time.

2. **Microsoft Azure** - Major program change July 2025. Max $5K self-service (was $150K).

3. **Cloud credits** - Most require NEW customers only. Can't double-dip.

4. **Annual renewals** - DigitalOcean and others require yearly re-application.

5. **NLnet/NGI funding** - Under EU budget pressure. Apply while available.
